# AI provenance

Who wrote what, and who verified it. This is the disclosure and audit trail for
AI involvement in this manuscript. It answers a different question from
[`05_ledger/provenance.md`](05_ledger/provenance.md), which records which script
produced which number; conflating the two loses both.

The author takes responsibility for every claim here. State which model(s)
were used and at which stages. The point of this file is that the
disclosure is specific enough to audit rather than a blanket sentence.

## Roles

| Code | Meaning |
|---|---|
| `H` | Human-originated: the idea, text, or decision came from Gilly |
| `A` | AI-generated first draft or implementation |
| `H→A` | Gilly specified, Claude executed |
| `A→H` | Claude drafted, Gilly revised substantively |
| `V:H` | Verified by Gilly |
| `V:T` | Verified by a re-runnable test or script in this repo |
| `V:S` | Verified against a cited external source |

A row is not complete until it carries a verification mark. Unverified `A` rows
are the ones a referee should be told about, and the ones to fix first.
