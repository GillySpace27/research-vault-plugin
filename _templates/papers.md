# Papers

Master tracking list of papers/manuscripts. Each entry carries a **Status:**
line that `/status` reads to sort it into a bucket. The `vault-status` skill
maps these to the paper six buckets (Untouched → Idea Scoped → Drafting →
Submitted / Under Review → Accepted → Published).

Distinct from `proposal-solicitations.md`: a proposal and a paper on the same
project are different objects with different clocks, even when one cites the
other. Track them separately.
